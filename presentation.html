Critical Problem: 48% Volume of False Network Alerts

Almost half of all incoming Cisco DNAC network notifications represent transient, self-healing events or stale backdated syslog messages that do not require human intervention.

Transient Flapping Events

Temporary interface flaps, momentary CPU spikes, and transient BGP peer drops automatically self-heal within 5 to 10 minutes. Naively ticketing these immediately creates massive noise.

ServiceNow Ticket Pollution

Legacy monitoring tools flood ServiceNow with duplicate incidents for a single underlying issue, cluttering SOC queues and obscuring true high-priority outages.

Stale / Backdated Telemetry

Delayed network telemetry pushes historical alerts (>24 hours old) into the pipeline, wasting SOC engineering hours investigating issues that resolved long ago.

Gemini Agentic Tool Calling

Driven by gemini-2.0-flash function calling. Executes multi-turn tool loops with 8 Python tools for querying alerts, device status, KPI trends, and DNAC REST endpoints.

Dual-Tier Retrieval Architecture

Enforces a MongoDB First Policy for instant sub-second local queries. Gracefully falls back to live Cisco DNAC REST APIs (/device-health, /issues) for real-time status.

Intent Classification & Clarification

Classifies query intent upfront into TEXT_ONLY, VISUALIZATION, or AMBIGUOUS. Intercepts ambiguous requests to prompt operators with interactive clarifying options.

Dynamic Recharts Spec & Citations

The generate_visualization tool emits structured JSON chart specs rendered natively in React (bar, line, pie, area) alongside verifiable citations.
