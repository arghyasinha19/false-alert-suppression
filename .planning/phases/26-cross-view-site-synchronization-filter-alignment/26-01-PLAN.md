## Objective

Connect site selection and location filtering bi-directionally across Regional Site Matrix, SRE High-Density Table, and Multi-Site Topology views (`SITE-07`, `SITE-08`). Validate with an automated contract test suite.

## Must-Haves (Goal-Backward Verification)

<must_haves>
### Truths
- Selecting a site in Regional Site Matrix view (`viewMode === 'matrix'`) or clicking its drilldown button switches view to `topology`, sets `selectedSite = site.code`, and transitions to `topologyLevel = 'lan'` (`SITE-07`).
- Active site cards in the matrix view render `.active-site` with distinct visual highlight when `selectedSite === site.code` (`SITE-07`).
- The multi-dimensional filter bar provides a `Site:` filter cluster with `All Sites (Global)` and site chips that synchronize with `selectedSite` and `topologyLevel` (`SITE-08`).

- Resetting filters resets `selectedSite` to `null` and `topologyLevel` to `'wan'`, maintaining global fleet visibility.
- `tests/test_cross_view_site_sync_contract.py` passes 100% of assertions verifying `SITE-07` and `SITE-08`.
- `npm run build` in `dashboard` compiles cleanly with zero errors.
- Full pytest regression suite passes with 0 failures.

## Step-by-Step Implementation

### Step 1: Add Site Filter Cluster to Filter Bar in `NetworkOperations.jsx`
1. In `NetworkOperations.jsx`, insert a `Site:` filter cluster in the filter bar:
   - `All Sites (Global)` chip active when `!selectedSite`.
   - Chip for each site in `siteMatrix` showing code and device count.
   - Clicking toggles between the site and `All Sites`.
2. Update `resetAllFilters` and `hasActiveFilters` to include `selectedSite`.
3. In `filteredDevices`, scope devices to `selectedSite` when `selectedSite` is set.

### Step 2: Make Table Location Cells Interactive in `NetworkOperations.jsx`
1. Render `.noc-table-loc-btn` in the SRE table Location column.
2. Clicking filters by that location, setting `selectedSite` and `topologyLevel = 'lan'`.

### Step 3: Enhance Site Matrix Cards in `NetworkOperations.jsx`
1. Add `.active-site` class to `.noc-site-card` when `selectedSite === site.code`.
2. Wire drilldown button to switch `viewMode` to `'topology'`, `selectedSite` to `site.code`, and `topologyLevel` to `'lan'`.

### Step 4: Add Styling to `App.css`
1. Style `.noc-table-loc-btn` with clean link/button styling, min-height >= 32px, and hover states.
2. Style `.noc-site-card.active-site` with purple glow border.

### Step 5: Author Contract Tests in `tests/test_cross_view_site_sync_contract.py`
1. Assert Site Matrix drilldown transitions viewMode to topology with selectedSite and lan level (`SITE-07`).
2. Assert active site highlighting in Site Matrix (`SITE-07`).
3. Assert Site filter cluster in filter bar with site chips (`SITE-08`).
4. Assert interactive location button in SRE Table (`SITE-08`).
5. Assert filter reset clears site scope (`SITE-08`).
