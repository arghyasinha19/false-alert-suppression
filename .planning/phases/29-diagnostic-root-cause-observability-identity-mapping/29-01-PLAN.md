## Step-by-Step Implementation

### Step 1: Add Site Extraction Helper in `dashboard/device_service.py`
1. Implement `extract_site_from_location_path(location_path: Optional[str]) -> Optional[str]`:
   - Splits on `/`, filters empty components.
   - For `"Global/EMEA/TR Istanbul/Umut Street"`:
     - Identifies city/site token (`"TR Istanbul"`).
     - Strips 2-letter country prefixes (`"TR "`, `"US "`, etc.), yielding `"Istanbul"`.
     - Returns `"Istanbul"` (or fallback to token).

### Step 2: Extract Diagnostics & Site in `extract_device_info_from_raw()`
1. In `extract_device_info_from_raw()`, extract:
   - `location_path`: `det.get("location") or inv.get("locationName") or inv.get("location")`.
   - `site_name`: `extract_site_from_location_path(location_path)`.
   - `diagnostics`:
     ```python
     fail_reason = inv.get("reachabilityFailureReason") or ""
     err_code = inv.get("errorCode")
     if not err_code and "snmp" in fail_reason.lower():
         err_code = "NCIM12013"

     diag_desc = None
     if "snmp" in fail_reason.lower() or err_code == "NCIM12013":
         diag_desc = "SNMP request timeout. Device may be unreachable or SNMP credentials configured on device may be different from Catalyst Center credentials."

     uptime_secs = inv.get("uptimeSeconds")
     try:
         uptime_secs = int(uptime_secs) if uptime_secs is not None else 0
     except (ValueError, TypeError):
         uptime_secs = 0

     reach_status = str(inv.get("reachabilityStatus", "")).lower()
     is_isolated = bool(uptime_secs > 300 and reach_status in ("unreachable", "false"))

     info["location_path"] = location_path
     info["site_name"] = site_name
     info["diagnostics"] = {
         "reachability_failure_reason": fail_reason or None,
         "error_code": err_code,
         "diagnostic_message": diag_desc,
         "uptime_seconds": uptime_secs if uptime_secs > 0 else None,
         "is_management_plane_isolated": is_isolated,
     }
     ```

### Step 3: Update `tests/test_device_telemetry_api.py`
1. Add `test_telemetry_diagnostics_and_site_extraction()`:
   - Feeds the captured Cisco 4331 ISR raw response.
   - Asserts `info["diagnostics"]["reachability_failure_reason"] == "SNMP Connectivity Failed"`.
   - Asserts `info["diagnostics"]["error_code"] == "NCIM12013"`.
   - Asserts `info["diagnostics"]["is_management_plane_isolated"] is True`.
   - Asserts `info["site_name"] == "Istanbul"`.
   - Asserts `info["location_path"] == "Global/EMEA/TR Istanbul/Umut Street"`.

### Step 4: Run Verification
1. Run `pytest tests/test_device_telemetry_api.py`.
2. Ensure all tests pass.
