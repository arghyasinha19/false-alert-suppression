## Step-by-Step Implementation

### Step 1: Update Identity & Diagnostics Resolution in `dashboard/src/NetworkOperations.jsx`
1. In `NetworkOperations.jsx` SRE Drawer:
   - Extract `resolvedSite`:
     ```javascript
     const rawLocation = liveDeviceInfo?.location_path || rawDeviceDetail.location || null;
     const resolvedSite = liveDeviceInfo?.site_name || extractSiteName(rawLocation) || selectedDevice.location || deriveLocation(selectedDevice.device_name);
     ```
   - Extract `resolvedHostname`:
     ```javascript
     const resolvedHostname = liveDeviceInfo?.hostname || rawNetworkDevice.hostname || rawDeviceDetail.nwDeviceName || (isIpAddress(selectedDevice.device_name) ? null : selectedDevice.device_name);
     ```
   - Extract diagnostics:
     ```javascript
     const diag = liveDeviceInfo?.diagnostics || {};
     const failureReason = diag.reachability_failure_reason || rawNetworkDevice.reachabilityFailureReason || (liveTelemetry?.reachable === false ? 'Unreachable' : null);
     const errorCode = diag.error_code || rawNetworkDevice.errorCode || (failureReason?.toLowerCase().includes('snmp') ? 'NCIM12013' : null);
     const isIsolated = diag.is_management_plane_isolated || (Boolean(vitals.uptime && vitals.uptime !== '—') && liveTelemetry?.reachable === false);
     const diagMessage = diag.diagnostic_message || (errorCode === 'NCIM12013' || failureReason?.toLowerCase().includes('snmp')
       ? 'SNMP request timeout. Device may be unreachable or SNMP credentials configured on device may be different from Catalyst Center credentials.'
       : null);
     ```

### Step 2: Render Management Plane Diagnostics Card
1. In Drawer Tab 1 (Vitals), directly above the hardware specifications card when `failureReason` exists:
   - Render:
     ```jsx
     {failureReason && (
       <div className="noc-inventory-card noc-diagnostic-card">
         <div className="noc-diag-header">
           <h4><AlertTriangle size={14} className="noc-warn-icon" /> Management Plane Diagnostics</h4>
           {errorCode && <span className="noc-err-code-badge">{errorCode}</span>}
         </div>
         <div className="noc-spec-row">
           <span className="noc-spec-label">Failure Reason</span>
           <span className="noc-spec-val text-warning">{failureReason}</span>
         </div>
         {isIsolated && (
           <div className="noc-spec-row">
             <span className="noc-spec-label">Operating State</span>
             <span className="noc-spec-val noc-isolation-badge">
               Node Running (Uptime {vitals.uptime}) • Management Plane Isolated
             </span>
           </div>
         )}
         {diagMessage && (
           <div className="noc-diag-remediation">
             <span className="noc-remediation-label">Controller Diagnostic:</span>
             <p className="noc-remediation-text">{diagMessage}</p>
           </div>
         )}
       </div>
     )}
     ```

### Step 3: Display Hostname & Clean Site in Inventory Cards
1. In "Network Location & Placement" card:
   - SRE Drawer displays `Site`: `{resolvedSite}`.
   - If `rawLocation` exists, show full path in tooltip or subtitle.
   - Add row: `Hostname`: `{resolvedHostname || '—'}`.
2. In Drawer Header:
   - When `selectedDevice.device_name` is an IP and `resolvedHostname` exists, show `resolvedHostname` as title with IP address pill.

### Step 4: Contract Tests & Verification
1. Add tests in `tests/test_frontend_sre_drawer_contract.py` asserting:
   - Management Plane Diagnostics card existence.
   - `NCIM12013` error code and isolation badge logic.
   - Authoritative hostname and site resolution.
2. Run `pytest tests/test_frontend_sre_drawer_contract.py`.
3. Run `npm run build` in `dashboard/`.
