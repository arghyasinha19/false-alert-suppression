## Objective

Update `dashboard/device_service.py` to extract authoritative hardware specifications (`model`, `serial`, `mac`, `os_version`, `ip_address`, `hostname`, `role`) directly from DNAC `raw_response.network_device` and `raw_response.device_detail`. Persist these enriched specs into MongoDB `device_telemetry`, preventing `"Unknown"` defaults when raw DNAC responses are present. Validate with comprehensive unit and contract tests in `tests/test_device_telemetry_api.py`.

## Step-by-Step Implementation

### Step 1: Implement Spec Harvester in `dashboard/device_service.py`
1. Define helper `extract_device_info_from_raw(raw_response: dict, fallback_info: Optional[dict] = None) -> dict`:
   - Inspect `raw_response.get("network_device")` and `raw_response.get("device_detail")`.
   - Extract:
     - `model`: `inventory.get("type") or inventory.get("platformId") or detail.get("nwDeviceType") or detail.get("platformId")`
     - `serial`: `inventory.get("serialNumber") or detail.get("serialNumber")`
     - `mac`: `inventory.get("macAddress") or detail.get("macAddress")`
     - `os_version`: `inventory.get("softwareVersion") or detail.get("softwareVersion")`
     - `ip_address`: `inventory.get("managementIpAddress") or detail.get("managementIpAddr") or detail.get("ip_addr_managementIpAddr")`
     - `hostname`: `inventory.get("hostname") or detail.get("nwDeviceName")`
     - `role`: `inventory.get("role") or detail.get("nwDeviceRole")`
   - Merge non-null, non-unknown values into `fallback_info` or `default_info`.

### Step 2: Integrate into `fetch_device_telemetry()`
1. In `fetch_device_telemetry()`, after `raw_health = dnac_client.get_device_health(device_id)`:
   - Extract `raw_resp = raw_health.get("raw_response")`.
   - If `raw_resp`: call `extract_device_info_from_raw(raw_resp, fallback_info=device_info)` and update `device_info`.
2. Ensure `cache_doc["device_info"]` in MongoDB update contains the enriched `device_info`.
3. In `get_or_resolve_device_id()`, if `device_id` was found in `alert_results` but `device_info` is `None`:
   - Query `telemetry_coll.find_one({"device_id": device_id})` or `{"device_name": device_name}` to retrieve cached `device_info` if available.

### Step 3: Add Automated Tests in `tests/test_device_telemetry_api.py`
1. Add `test_telemetry_raw_response_hardware_extraction()`:
   - Simulates live health returning raw ISR 4331 response with `"network_device"` and `"device_detail"`.
   - Asserts endpoint returns `model`, `serial`, `mac`, `os_version`, and `ip_address` extracted directly from the raw response.
2. Add `test_telemetry_persists_extracted_device_info_to_mongo()`:
   - Verifies MongoDB `device_telemetry.update_one` is called with the extracted hardware specs.
