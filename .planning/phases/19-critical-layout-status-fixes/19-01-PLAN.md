## Objective

Fix the responsive layout collapse below 1100px in `.content-area` by replacing rigid viewport constraints with pure flexbox boundaries (`min-width: 0`, `max-width: 100%`), auto-collapsing the navigation sidebar to the 72px icon rail below 1100px while preserving manual toggle control, introducing an explicit `@media (max-width: 1100px)` responsive block for compact header padding and grid reflow, and strictly isolating wide table card horizontal overflow.
