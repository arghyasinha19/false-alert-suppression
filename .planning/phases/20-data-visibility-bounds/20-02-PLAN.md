## Objective

Standardize table scrollbars across the application to permanently visible 8px high-contrast slate thumbs with sunken tracks; implement dynamic 28px horizontal gradient edge masks (`::before` / `::after`) across all 5 wide dashboard tables with scroll-state fade-outs and bottom clearance for scrollbar drag; enforce sticky headers (`position: sticky; top: 0; backdrop-filter: blur(8px)`) across all scrollable table views; render prominent `"Showing {visible} of {total} {items}"` counter chips with active filter indicators; and cap dense vertical lists (10 rows in tables, 5 alerts in the SRE details drawer) with progressive disclosure toggles.

### Task 2 — Reusable `TableScrollWrapper` with Dynamic 28px Horizontal Edge Masks (`D-09`, `D-10`, `D-11`, `D-12`)

<read_first>
- `dashboard/src/App.css` (lines 790-830, 2500-2600)
- `.planning/phases/20-data-visibility-bounds/20-UI-SPEC.md` §3. Horizontal Table Edge Gradient Masks
- `.planning/phases/20-data-visibility-bounds/20-CONTEXT.md` §Decisions D-09, D-10, D-11, D-12
</read_first>

<action>
1. Create `dashboard/src/components/TableScrollWrapper.jsx`:
   - Component props: `children`, `className = ''`, `maxHeight = null`.
   - Uses `containerRef` on the scrollable container.
   - States: `hasOverflowLeft` (boolean) and `hasOverflowRight` (boolean).
   - Functions `checkOverflow`:
     ```javascript
     const el = containerRef.current;
     if (!el) return;
     const { scrollLeft, scrollWidth, clientWidth } = el;
     setHasOverflowLeft(scrollLeft > 2);
     setHasOverflowRight(scrollLeft + clientWidth < scrollWidth - 2);
     ```
   - Attaches `scroll` event listener with `passive: true`.
   - Uses `ResizeObserver` on `containerRef.current` to re-check overflow when window or table content resizes.
   - Renders container structure:
     ```jsx
     <div className={`table-scroll-wrapper ${hasOverflowLeft ? 'has-overflow-left' : ''} ${hasOverflowRight ? 'has-overflow-right' : ''} ${className}`}>
       <div 
         ref={containerRef} 
         className="table-scroll-container"
         style={maxHeight ? { maxHeight } : undefined}
       >
         {children}
       </div>
     </div>
     ```
2. In `dashboard/src/App.css`:
   - Style `.table-scroll-wrapper`:
     ```css
     .table-scroll-wrapper {
       position: relative;
       width: 100%;
       min-width: 0;
       overflow: hidden;
     }
     .table-scroll-container {
       width: 100%;
       overflow-x: auto;
       overflow-y: auto;
     }
     /* Edge Gradient Masks */
     .table-scroll-wrapper::before,
     .table-scroll-wrapper::after {
       content: '';
       position: absolute;
       top: 0;
       bottom: 8px; /* Leave 8px scrollbar track unblocked */
       width: 28px;
       pointer-events: none;
       z-index: 4;
       opacity: 0;
       transition: opacity 0.2s ease;
     }
     .table-scroll-wrapper::before {
       left: 0;
       background: linear-gradient(to right, var(--card-bg), transparent);
     }
     .table-scroll-wrapper::after {
       right: 0;
       background: linear-gradient(to left, var(--card-bg), transparent);
     }
     .table-scroll-wrapper.has-overflow-left::before {
       opacity: 1;
     }
     .table-scroll-wrapper.has-overflow-right::after {
       opacity: 1;
     }
     ```
3. Wrap all 5 wide tables with `TableScrollWrapper`:
   - **Detailed Traceability Matrix** in `FalseAlertMetrics.jsx`
   - **Device Ranking Table** in `FalseAlertMetrics.jsx`
   - **SRE High-Density Table** in `NetworkOperations.jsx`
   - **Regional Site Matrix** in `NetworkOperations.jsx`
   - **Alert Patterns Table** in `AlertPatterns.jsx`
</action>
