## Objective

Constrain the interactive SVG topology graph canvas to its own bounds with dynamic viewport-proportional height `clamp(560px, calc(100vh - 280px), 780px)`, prevent page scroll hijacking by requiring `Ctrl` / `Cmd` + scroll to zoom (showing a floating toast hint pill when scrolling without modifiers), clamp pointer panning to soft boundaries so diagram nodes are never dragged off-screen (minimum 25% visibility clamp), and provide a dedicated Fullscreen / Expanded View mode in the floating toolbar with `Escape` key exit.

<action>
1. In `dashboard/src/components/TopologyGraphView.jsx`:
   - Add state: `const [showWheelHint, setShowWheelHint] = useState(false);` and ref: `const wheelHintTimerRef = useRef(null);`.
   - Update `handleWheel` callback:
     - Check modifier: `const hasModifier = e.ctrlKey || e.metaKey;`
     - If `!hasModifier`:
       - Do **NOT** call `e.preventDefault()`. Allow natural browser page scroll!
       - Clear any active `wheelHintTimerRef.current`.
       - Set `setShowWheelHint(true)`.
       - Set timer `wheelHintTimerRef.current = setTimeout(() => setShowWheelHint(false), 2000);`
       - Return early without updating `transform`.
     - If `hasModifier`:
       - Call `e.preventDefault()`.
       - Zoom towards mouse cursor coordinate (clamped `0.4` to `2.2`).
       - If `showWheelHint` is true, clear timer and set `setShowWheelHint(false)`.
   - Cleanup timer on unmount: `return () => { if (wheelHintTimerRef.current) clearTimeout(wheelHintTimerRef.current); };`.
   - Render floating hint toast inside `.noc-topology-graph-container`:
     ```jsx
     {showWheelHint && (
       <div className="noc-wheel-zoom-hint" role="status" aria-live="polite">
         Use Ctrl + scroll to zoom
       </div>
     )}
     ```
2. In `dashboard/src/App.css`:
   - Style `.noc-wheel-zoom-hint`:
     - `position: absolute; bottom: 24px; left: 50%; transform: translateX(-50%); z-index: 20;`
     - `padding: 6px 14px; font-size: 0.75rem; font-weight: 600; color: var(--text-primary);`
     - `background: rgba(15, 23, 42, 0.88); backdrop-filter: blur(12px);`

2. In `dashboard/src/components/TopologyGraphView.jsx`:
   - Update `handlePointerMove` to implement soft boundary pan clamping (`D-03`):
     - Calculate tentative coordinates: `const rawX = startTransform.x + dx;` and `const rawY = startTransform.y + dy;`.
     - Soft margin calculation: keep at least 25% of graph bounding box (`canvasDimensions.width * transform.k` and `canvasDimensions.height * transform.k`) visible inside container:
       ```javascript
       const visibleW = canvasDimensions.width * transform.k;
       const visibleH = canvasDimensions.height * transform.k;
       const minX = -(visibleW * 0.75);
       const maxX = containerSize.width - (visibleW * 0.25);
       const minY = -(visibleH * 0.75);
       const maxY = containerSize.height - (visibleH * 0.25);
       
       const clampedX = Math.min(maxX, Math.max(minX, rawX));
       const clampedY = Math.min(maxY, Math.max(minY, rawY));
       ```
     - Set clamped transform: `setTransform({ ...startTransform, x: clampedX, y: clampedY });`.
</action>

### Task 3 — Fullscreen / Expanded Canvas Mode with Toolbar Toggle & Esc Key Exit (`D-04`)

- `.planning/phases/20-data-visibility-bounds/20-UI-SPEC.md` §Copywriting & Fullscreen Mode
- `.planning/phases/20-data-visibility-bounds/20-CONTEXT.md` §Decision D-04
</read_first>

<action>
1. In `dashboard/src/components/TopologyGraphView.jsx`:
   - Import `Minimize2` from `'lucide-react'` alongside `Maximize2`.
   - Add state: `const [isFullscreen, setIsFullscreen] = useState(false);`.
   - Add toggle handler: `const toggleFullscreen = () => setIsFullscreen(prev => !prev);`.
   - Add `useEffect` listener for `keydown`:
     ```javascript
     useEffect(() => {
       const handleKeyDown = (e) => {
         if (e.key === 'Escape' && isFullscreen) {
           setIsFullscreen(false);
         }
       };
       window.addEventListener('keydown', handleKeyDown);
       return () => window.removeEventListener('keydown', handleKeyDown);
     }, [isFullscreen]);
     ```
   - Update container class name:
     ```jsx
     className={`noc-topology-graph-container ${isPanning ? 'is-panning' : ''} ${isFullscreen ? 'fullscreen' : ''}`}
     ```
   - In floating toolbar, add a dedicated toggle button:
     ```jsx
     <button
       type="button"
       className={`noc-graph-control-btn ${isFullscreen ? 'active' : ''}`}
       onClick={toggleFullscreen}
       title={isFullscreen ? "Exit Fullscreen Canvas (Esc)" : "Expand Topology View"}
       aria-label={isFullscreen ? "Exit Fullscreen Canvas" : "Expand Topology View"}
     >
       {isFullscreen ? <Minimize2 size={13} /> : <Maximize2 size={13} />}
       <span>{isFullscreen ? 'Exit' : 'Expand'}</span>
     </button>
     ```
2. In `dashboard/src/App.css`:
   - Style `.noc-topology-graph-container.fullscreen`:
     ```css
     .noc-topology-graph-container.fullscreen {
       position: fixed;
       inset: 0;
       width: 100vw;
       height: 100vh;
       max-height: 100vh;
       z-index: 1000;
       border-radius: 0;
       box-shadow: none;
       border: none;
     }
     .noc-topology-graph-container.fullscreen .noc-graph-controls-toolbar {
       top: 24px;
       right: 24px;
       z-index: 1010;
     }
     ```
</action>
