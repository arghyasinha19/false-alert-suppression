## Objective

Enforce a 32px visible min-height on all interactive buttons, filter pills, search inputs, and selects, combined with a 44x44px transparent touch target expander (`.touch-target-expand::before`) for compact icon buttons (`UI-07`). Standardize the typography hierarchy to 13px (0.8125rem) for primary body text/tables/filters and 12px (0.75rem) for headers/badges/metadata/captions, completely eliminating sub-12px CSS (`UI-07`). Equip all form controls with explicit labels (`<label htmlFor="...">`), inject `scope="col"` and `aria-sort` on table headers, add `<caption className="sr-only">` to all data tables (`UI-17`), and lock compliance with automated pytest contract tests.

## Threat Model

<threat_model>
- **TM-03 (Accidental Layout Shift / Table Header Clipping):** Increasing hit area to 44px or font-size could distort compact tables or cause horizontal overflow if handled with raw padding. *Mitigation:* Visual min-height is kept strictly to 32px; 44px touch target is achieved via transparent `::before` pseudo-element with `pointer-events: auto` and negative positioning, preserving visual density while providing generous touch boundaries.
- **TM-04 (Screen-Reader Disorientation):** Multiple unlabelled data tables could disorient screen reader users navigating by landmarks. *Mitigation:* Each data table includes a distinct, descriptive `<caption className="sr-only">` clearly articulating its dataset and purpose.
</threat_model>
