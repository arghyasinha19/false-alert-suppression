## Step-by-Step Implementation

### Step 1: Implement Breadcrumb Bar & Site Switcher in `TopologyGraphView.jsx`
1. When `topologyLevel === 'lan'`, render `.noc-topology-breadcrumbs` in the top toolbar:
   - Root button: `<button className="noc-breadcrumb-root" onClick={onReturnToWan}><Globe size={13} /> Global WAN Interconnect</button>`
   - Chevron: `<ChevronRight size={13} className="noc-breadcrumb-sep" />`
   - Active site item: `<span className="noc-breadcrumb-site">{currentSiteLabel}</span>`
   - Site switcher `<select className="noc-site-switcher-select" value={selectedSite} onChange={e => onSelectSite(e.target.value)}>` listing all registered sites with formatted status labels.
2. Render `.noc-wan-back-btn` with `<ArrowLeft size={13} /> Back to Global WAN`.

### Step 2: Implement Site-Scoped LAN Graph & Banner in `TopologyGraphView.jsx`
1. Filter devices strictly by `selectedSite` when `topologyLevel === 'lan'`:
   - Compute tier buckets (Core, Distribution, Access) exclusively from the site's fleet.
   - Render site header banner displaying site flag, site code, site label, total devices, active alerts, avoided tickets, and uptime summary.
2. In the filter match pill, display `Filtered: ${matchCount} of ${siteDevices.length} devices in ${selectedSite}` when filters are active, and ensure `onResetFilters` clears the filters without leaving the site.

### Step 3: Add Styling to `App.css`
1. Define `.noc-topology-breadcrumbs`, `.noc-breadcrumb-root`, `.noc-breadcrumb-sep`, `.noc-breadcrumb-site`, `.noc-site-switcher-select`, and `.noc-site-switcher-wrapper`.
2. Ensure minimum touch targets (>= 32px), high contrast (WCAG AAA compliant), and consistent typography tokens (`--font-xs`, `--font-sm`).

### Step 4: Author Contract Tests in `tests/test_site_lan_drilldown_contract.py`
1. Verify breadcrumb trail element, root click callback, and chevron separator (`SITE-05`).
2. Verify site switcher selector element with options and change handler (`SITE-04`).
3. Verify site device scoping and 3-tier LAN rendering (`SITE-04`).
4. Verify site-scoped filter count badge and filter clear behavior (`SITE-06`).
5. Verify CSS rules for breadcrumbs and site switcher in `App.css`.
