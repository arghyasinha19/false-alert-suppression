### Task 1 — Declare 6 Typography Tokens & Map CSS (`UI-09-22`, `D-03`, `D-04`)

<read_first>
- `dashboard/src/index.css`
- `dashboard/src/ChatPanel.css`
- `dashboard/src/App.css`
</read_first>

<action>
1. In `dashboard/src/index.css`, declare the 6 typography scale tokens in `:root`:
   ```css
   /* 6-Step Typography Scale Tokens (UI-09-22) */
   --font-xs: 0.75rem;     /* 12px / 0.75rem - Badges, table headers, metadata tags, captions, chips */
   --font-sm: 0.8125rem;   /* 13px / 0.8125rem - Body text, table cells, form controls, filter pills */
   --font-md: 0.9375rem;   /* 15px / 0.9375rem - Card titles, subheadings, drawer section labels */
   --font-lg: 1.125rem;    /* 18px / 1.125rem - Section titles, modal headers, major numbers */
   --font-xl: 1.5rem;      /* 24px / 1.5rem - Primary KPI card values, medium metric counters */
   --font-2xl: 2.125rem;   /* 34px / 2.125rem - Executive health score & hero numbers */
   ```
2. In `dashboard/src/ChatPanel.css`:
   - Replace arbitrary `font-size` declarations (such as `0.7rem`, `0.72rem`, `0.8rem`, `0.85rem`, `0.95rem`, `1.1rem`) with the corresponding tokens:
     - `0.75rem` / `12px` $\to$ `var(--font-xs)`
     - `0.8125rem` / `13px` $\to$ `var(--font-sm)`
     - `0.9375rem` / `15px` $\to$ `var(--font-md)`
     - `1.125rem` / `18px` $\to$ `var(--font-lg)`
3. In `dashboard/src/App.css`:
   - Standardize all arbitrary font-size rules (e.g. `0.72rem`, `0.78rem`, `0.85rem`, `0.95rem`, `1.05rem`, `1.2rem`, `1.85rem`) to the nearest standard scale token (`var(--font-xs)`, `var(--font-sm)`, `var(--font-md)`, `var(--font-lg)`, `var(--font-xl)`, `var(--font-2xl)`).
   - Exempt internal SVG coordinate dimensions.
</action>

Run `npm run build` from `dashboard` to ensure all CSS syntax is valid and compiles cleanly.
