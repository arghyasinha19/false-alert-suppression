## Step-by-Step Implementation

### Step 1: Implement WAN Interconnect Link Generator in `TopologyGraphView.jsx`
1. Define WAN link topology interconnects:
   - `UK-LON` ↔ `DE-FRA` (24ms, 100G Backbone)
   - `UK-LON` ↔ `US-NY` (115ms, Transatlantic Subsea)
   - `DE-FRA` ↔ `SG-SIN` (128ms, Eurasia Terrestrial)
   - `SG-SIN` ↔ `IN-MUM` (42ms, APAC Subsea)
   - `SG-SIN` ↔ `AU-SYD` (92ms, Oceanic Link)
   - `US-NY` ↔ `US-CHI` (18ms, Inter-City Metro)
   - `UK-LON` ↔ `UK-MAL` (6ms, Regional Metro)
2. Compute smoothed cubic bezier paths (`M srcX srcY C cpx1 cpy1, cpx2 cpy2, tgtX tgtY`) connecting the boundaries of the source and target macro site nodes.
3. Compute the link midpoint `(midX, midY)` for positioning latency badges.
4. Derive link status: if either connected site is `critical`, link is `critical`; if either is `degraded`, link is `warning`; otherwise `nominal`.

### Step 2: Implement Animated Flow & Latency Badges
1. Render underlying background stroke and animated foreground stroke with class `.noc-wan-link.active-flow`.
2. Add `<g className="noc-wan-link-badge-group">` at `(midX, midY)` with a rounded pill rect (`rx="10"`, `width="54"`, `height="22"`) and text showing latency (e.g., `24ms`).
3. Add hover state (`hoveredWanEdge`) highlighting the edge and showing title tooltip with bandwidth, latency, packet loss, and connected site names.

### Step 3: Add CSS Keyframe Flow Animations in `App.css`
1. Define `@keyframes wanFlow` with `stroke-dashoffset` translation.
2. Define `.noc-wan-link.nominal`, `.noc-wan-link.warning`, and `.noc-wan-link.critical` styles.
3. Define `.noc-wan-link-badge` styling with theme-aware background, border, and typography (`--font-xs`).

### Step 4: Create Contract Test Suite `tests/test_multi_site_wan_contract.py`
1. Test Level 1 WAN mode declaration and macro node rendering in `TopologyGraphView.jsx`.
2. Test site health rollup badges and blast radius calculation in `TopologyGraphView.jsx`.
3. Test inter-site WAN link generation, bezier path calculation, and latency badges.
4. Test presence of `@keyframes wanFlow` and `.blast-radius-halo` styles in `App.css`.
5. Test header level badge and toolbar controls.
