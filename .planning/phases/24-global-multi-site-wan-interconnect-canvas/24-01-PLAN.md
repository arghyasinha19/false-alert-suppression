## Step-by-Step Implementation

### Step 1: Add Level 1 WAN Presentation State & Coordinates in `TopologyGraphView.jsx`
1. Add `topologyLevel` prop (default `'wan'`) and `selectedSite` prop to `TopologyGraphView.jsx`.
2. Compute geographic/regional layout coordinates for registered sites:
   - EMEA cluster (left-center): `UK-LON`, `UK-MAL`, `DE-FRA`
   - Americas cluster (top-center/left): `US-NY`, `US-CHI`
   - APAC cluster (right-center): `SG-SIN`, `IN-MUM`, `AU-SYD`
3. Aggregate site devices, active alerts, avoided tickets, health status (`nominal`, `degraded`, `critical`), and blast radius percentage:
   $$\text{blastRadius} = \text{Math.round}\left(\frac{\text{critical} + \text{warning}}{\text{totalDevices}} \times 100\right)$$

### Step 2: Implement Macro Site Node Component (`.noc-wan-site-node`)
1. Render each site as an interactive SVG `<foreignObject>` or SVG card:
   - Width: `240px`, Height: `110px`.
   - Header: Regional flag, site code, site label, and status badge (`NOMINAL ●`, `DEGRADED ⚠`, `CRITICAL ✖`).
   - Body stats: Registered devices count, active alert pill, avoided ticket counter with `Zap` icon.
   - Footer: Blast radius chip and interactive "Drill Down →" action button (`min-height: 32px`).
2. Add perimeter SVG `<circle>` or `<rect>` halo with class `.blast-radius-halo` for sites with active degradation.

### Step 3: Implement Header Indicator Banner & Level Status
1. Add `.noc-topology-level-badge` to the canvas toolbar:
   - Displays `<Globe size={13} /> GLOBAL WAN TOPOLOGY (LEVEL 1)`.
   - Displays pill with `${sites.length} Connected Sites • Fleet Resilience ${resilienceScore}%`.

### Step 4: Add CSS Styling in `App.css`
1. Define styles for `.noc-wan-site-node`, `.noc-wan-site-header`, `.blast-radius-halo`, and `@keyframes blastRadiusPulse`.
2. Ensure full theme compatibility across light and dark modes with high-contrast text and border tokens.
