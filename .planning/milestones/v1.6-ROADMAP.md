# Milestone v1.6: Live DNAC Assurance Telemetry & Asset Integration

**Status:** ✅ SHIPPED 2026-10-05  
**Phases:** 13-15  
**Total Plans:** 3  

## Overview

Bridge the Network Operations Center directly with live Cisco DNA Center Assurance and Device Inventory APIs, replace client-side simulated drawer vitals and artificial poll timeouts with real backend endpoints, add live provenance indicators, and deliver an interactive SRE workstation with zero-delay fleet synchronization.

## Phases

### Phase 13: DNAC Client Assurance & Device Extensions
**Goal**: Extend `DNACClient` with robust methods querying Cisco DNA Center's Network Device (`/dna/intent/api/v1/network-device`) and Device Health (`/dna/intent/api/v1/device-health`) APIs with graceful error handling and fallbacks.  
**Plans**: 1 plan  

Plans:
- [x] 13-01: Implement device lookup, health metrics retrieval, and 401 retry recovery in `DNACClient`

**Details:**
- `DNACClient.get_device_by_name_or_ip()` parses device inventory details by hostname or management IP.
- `DNACClient.get_device_health()` queries real CPU %, RAM %, packet drop %, interface errors, and reachability.
- Added custom exception hierarchy `DNACError`, `DeviceNotFoundError`, and `DNACConnectionError` in `app/exceptions.py`.
- Automated token re-authentication on HTTP 401 responses.

---

### Phase 14: Backend Live Polling & Telemetry Endpoints
**Goal**: Implement FastAPI endpoints for device telemetry lookup and on-demand live polling in `dashboard/api.py`, integrating database state with real-time DNAC verification.  
**Plans**: 1 plan  

Plans:
- [x] 14-01: Create telemetry and live-polling FastAPI endpoints with MongoDB caching and offline fallbacks

**Details:**
- Created `dashboard/device_service.py` with two-tier UUID resolution (cache first, DNAC inventory fallback).
- Added `GET /api/devices/{device_name}/telemetry` (and alias `/api/device/...`) returning 9-key vitals and hardware specs.
- Added `POST /api/devices/{device_name}/live-poll` (and alias `/api/device/...`) re-verifying active alerts and refreshing telemetry.
- Caches live vitals in MongoDB collection `device_telemetry`, falling back to `source: "cached_offline"` or `source: "offline"`.
- Added 8 automated tests in `tests/test_device_telemetry_api.py`.

---

### Phase 15: Frontend SRE Drawer Live Wire-Up
**Goal**: Connect the slide-out drawer in `NetworkOperations.jsx` to the new live telemetry and polling endpoints, replacing mock calculations and simulated timeouts.  
**Plans**: 1 plan  

Plans:
- [x] 15-01: Wire drawer telemetry tabs and "Poll DNAC" action button to live API with real-time feedback

**Details:**
- Initiates `GET /api/devices/{device_name}/telemetry` immediately when drawer opens with `AbortController` cancellation.
- Header status pills render dual provenance indicators: `● DNAC LIVE` (green), `⟳ CACHED` (amber), or `○ OFFLINE` (slate).
- Tab banners in Assurance Telemetry and Device Inventory display sync timestamps and quick retry buttons.
- "Poll DNAC" button makes real HTTP `POST /api/devices/{device_name}/live-poll` call with spinner and toast notifications.
- Propagates fleet-wide refresh via `onRefresh()` to update device cards, health badges, and tables across all views.
- Added contract tests in `tests/test_frontend_sre_drawer_contract.py`.

## Milestone Summary

**Key Decisions:**
- Decision: Two-tier UUID resolution in `device_service.py` (Rationale: Fast lookups via MongoDB cache with dynamic fallback).
- Decision: Non-blocking HTTP 200 fallbacks on offline DNAC (Rationale: Prevents UI crashes and preserves offline demoability).
- Decision: Dual provenance badges in header and tab banners (Rationale: SREs know data origin at a glance).
- Decision: Fleet-wide `onRefresh()` call after live poll (Rationale: Synchronizes device state across all 3 representation modes).
- Decision: Omit Phase 16 daemon orchestration bundling and standalone CLI tool (Rationale: Independent `dnac_sync.py` and pytest test suites satisfy operational and testing needs).

**Issues Resolved:**
- Replaced client-side simulated telemetry numbers with authentic Cisco DNA Center Assurance vitals.
- Replaced artificial `setTimeout` 1500ms delay with real live-polling HTTP calls.
- Resolved potential race conditions on rapid drawer switching via `AbortController`.

**Issues Deferred:**
- WebSockets streaming for telemetry metrics instead of polling (future milestone).
- Dynamic interface flap timeline graph per port (future milestone).

**Technical Debt Incurred:**
- None. All new endpoints and frontend wire-ups include comprehensive tests with 100% clean linter checks and production builds.
