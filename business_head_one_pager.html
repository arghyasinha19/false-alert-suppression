Problem & Solution Delivered

  • The Problem: The SOC is overwhelmed by noisy Cisco DNAC webhooks. Almost half are transient (self-healing) or stale. This floods ServiceNow with duplicate incidents, causing high MTTR and analyst fatigue.
  • The Solution: An event-driven Hybrid Agentic Platform intercepts webhooks before ticketing. It applies sequential filtering, ML classification, async environmental verification, and intelligent ticket deduplication.
  • Conversational UI: A ChatOps dashboard allows tier-1 operators to query complex network trends, device health, and suppression statistics using natural language instead of complex query syntaxes.

Autonomous Processing Stages

Ingress Validation
Deterministically evaluates incoming alerts against time thresholds, instantly suppressing stale or backdated syslog messages without downstream processing.
Predictive Classification
Analyzes alert text and historical patterns using machine learning to predict if an issue is likely to self-resolve or if it requires human intervention.
Deferred Environment Verification
Places predicted transient alerts into an asynchronous delay queue. After the window expires, it actively re-queries the live network environment to confirm self-healing.
Intelligent ITSM Management
Deduplicates tickets by appending context to existing active incidents, reopening recently closed ones, and only creating net-new tickets when necessary.
Conversational Operations Assistant
Provides an interactive AI chat interface that autonomously selects tools to fetch device history, query databases, and generate dynamic visualizations based on user intent.

Core AI, ML & Agentic Technologies

The platform is considered "Agentic" because it employs dynamic routing, environment feedback loops, persistent memory, and autonomous tool selection, rather than static linear scripts. It relies on a suite of generalized intelligence layers:

  • Deep Learning Inference: A DistilBERT Transformer deployed via ONNX runtime performs high-speed, edge-efficient NLP classification on incoming alert payloads.
  • Statistical Machine Learning: TF-IDF vectorization paired with ensemble classifiers provides a robust fallback and feature-extraction layer for structured text analysis.
  • Large Language Models (LLMs): Google Gemini 2.0 Flash powers the reasoning engine, operating in a ReAct loop to interpret intent, invoke live API tools, and synthesize natural language answers.
  • Stateful Orchestration: LangGraph state machines coordinate the entire pipeline, enabling cyclic graphs, shared memory, and dynamic pathing based on intermediate outputs.
