1. Problem Statement
  • 48% Alert Noise Volume: Unvalidated Cisco DNAC webhooks flood SOC engineering queues with transient, self-healing link flaps and stale syslog messages.
  • ServiceNow Ticket Pollution: Naive ticketing systems create hundreds of duplicate incidents for single underlying events, cluttering queues.
  • High MTTR & SOC Fatigue: Engineers spend 85% of initial triage hours investigating historical (>24h) or temporary alerts that self-heal automatically.
2. Solution Delivered
  • LangGraph Multi-Agent Engine: 4 sequential backend agents with a Supervisor router node to suppress, classify, defer, and deduplicate alerts dynamically.
  • 15-Min DLX Non-Blocking Delay Loop: RabbitMQ Dead-Letter Exchange holds transient alerts in a wait queue before re-checking live DNAC APIs.
  • Gemini 2.0 AI ChatOps Assistant: Natural language assistant executing multi-turn tool loops with sub-second MongoDB/DNAC retrieval and dynamic Recharts UI.

4. Agent 5: Gemini 2.0 Tool-Calling Registry (8 Specialized Tools)

When network operators ask natural language questions, Agent 5 analyzes intent (TEXT_ONLY, VISUALIZATION, AMBIGUOUS) and executes function calls against MongoDB and Cisco DNAC REST APIs:

1. query_alerts
Searches MongoDB with device, severity, or category filters.
2. get_device_status
Aggregates device total alerts, backdated counts, & active alerts.
3. get_device_history
Fetches historical alert logs sorted newest-first for timeline analysis.
4. get_kpi_summary
Computes overall suppression rates, ticket avoidance, and daily series.
5. query_dnac_issue
Queries Cisco DNAC live API for issue status by instance UUID.
6. query_dnac_device_health
Resolves device names to UUIDs and queries live hardware health.
7. call_dnac_rest_api
Autonomous execution tool for calling any Cisco DNAC REST endpoint.
8. generate_visualization
Emits structured JSON chart specs rendered natively in Recharts UI.
